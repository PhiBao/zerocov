# Bob session evidence — `bob_sessions/`

The IBM Bob 2.0 Hackathon guide requires each participant to export **Bob task
session summary screenshots** into this folder as evidence of Bob usage. This folder
is that evidence.

## Naming convention

`<project>_task<NN>_<short-description>_summary.png`

Use PNG for text clarity. Include the project/team name, task number, and a short
description, e.g. `zerocov_task01_full_session_summary.png`.

## How these were captured

In Bob IDE: **Tasks** → select the task → select the task header → *task session
consumption summary* appears → screenshot (PNG) → save here.
